# ZENVORA Platform

Premium multilingual public website for ZENVORA.

## Included
- Responsive public homepage
- Black, purple and chrome-inspired visual identity
- FASHION, FOOD, GAMING, HOTELS and BARBER product presentation
- Portuguese, Spanish and English language selector
- Language preference saved in the browser
- WhatsApp support link
- Mobile navigation

## Run locally
This is a static website and does not require a build step. Open `index.html` in a browser, or use any static web server.

## Publish
You can publish this static version using a static hosting provider. This version is only the public presentation layer.

## Important: not implemented yet
Registration, login, database, customer/admin dashboards, subscriptions, payment processing, AI assistants and WhatsApp Business integrations are not included in this first frontend package. They require backend services, secure configuration and testing. Do not accept payments or promise working bots based on this frontend alone.
